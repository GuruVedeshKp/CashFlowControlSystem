# CFCS - Credit Follow-up & Collection System

A mobile-first receivables and collections management application for small businesses.

## Features
- Customer management
- Receivables tracking
- Partial payments
- Payment history
- WhatsApp reminders
- Reminder history
- PDF invoice generation
- Document upload
- Dashboard analytics
- Customer ledger

## Tech Stack
Frontend:
- Flutter

Backend:
- NestJS
- PostgreSQL
- TypeORM
